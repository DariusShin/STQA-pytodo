# 08_Final_QA_Report - SQA, Metrics and Final Quality Evaluation

Week 8 calculates the test and defect metrics and gives the final quality assessment, residual risks and prioritised recommendations.

| File / folder | Contents |
| --- | --- |
| [W8_Report.md](W8_Report.md) | Final integrated QA evaluation: quality assessment, metrics, evidence by ISO/IEC 25010 characteristic, residual risks, findings, process improvements, recommendations |
| [metrics.md](metrics.md) | Full metrics tables: execution per phase, defects by severity/priority, module and phase, density |
| [evidences/](evidences/) | Charts: execution by phase, defects by severity, module and phase |

Week 8 executes no new tests, so it has no `test_cases.md` or `defects.md`; its metrics are computed from the project-level [master repository](../master_test_cases.md), [RTM](../rtm.md) and [defect log](../consolidated_defect_logs.md).
