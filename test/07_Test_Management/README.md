# 07_Test_Management - Test Planning, Traceability and Defect Management

Week 7 sets out the test plan and strategy and consolidates every test case, requirement link and defect of Weeks 1-6 into one repository, one RTM and one defect log.

| File | Contents |
| --- | --- |
| [W7_Report.md](W7_Report.md) | Week 7 report: software test plan, test strategy, RTM and repository summaries, defect management, execution and regression status |
| [test/rtm.md](../rtm.md) | Requirements traceability matrix, REQ-001 to REQ-014 |
| [test/master_test_cases.md](../master_test_cases.md) | Master test-case repository: all 302 cases of Weeks 1-6, linked to their full records |
| [test/consolidated_defect_logs.md](../consolidated_defect_logs.md) | Consolidated defect log, DEF-001 to DEF-037 |

The RTM, repository and defect log cover the whole project, so they are kept in `test/`. Week 7 executes no new tests and has no `test_cases.md`, `defects.md` or `evidences/` of its own; each case and defect links to its record and evidence in the weekly folder.
